Quatrième jour : Responsive Design

- 1. Ce que j'ai appris

J'ai découvert le principe du Responsive Design. Il permet d'adapter un site web aux différentes tailles d'écran.

J'ai découvert :

* Les Media Queries avec `@media`.
* La différence entre les écrans mobiles et les grands écrans.
* L'utilisation de `max-width` et `min-width`.
* Le principe du Mobile First.

- 2. Ce que j'ai appliqué


J'ai commencé à réfléchir à l'adaptation de mes pages aux écrans mobiles. J'ai essayé d'utiliser CSS pour modifier la présentation selon la taille de l'écran.


- 3. Difficultés rencontrées


J'ai eu besoin de pratiquer davantage pour comprendre les Media Queries et leur fonctionnement.



- 4. Bilan de la journée

J'ai découvert les bases du Responsive Design et compris son importance dans la création d'un site web accessible sur différents appareils.
