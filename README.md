 Présentation du projet

Ce projet contient une documentation sur les bases du HTML et du CSS.

L'objectif est de comprendre les balises HTML, leur utilisation et les bases de la mise en forme avec CSS.
Ce que j'ai appris

* Les balises sémantiques
* Les types de balises HTML
* La différence entre 'class' et 'id'
* L'intégration d'un fichier CSS externe
* L'insertion des images
* L'utilisation des liens
* L'organisation du contenu avec 'div', 'main', 'section' et 'article'
* L'utilisation de 'ul' et 'li'
* La différence entre 'span' et 'div'

Technologies utilisées

* HTML5
* CSS3
Ce que j'ai pratiqué

J'ai créé une page HTML pour organiser mes notes et j'ai utilisé CSS pour modifier son apparence.
